Bonus · Beyond Claude Code

Claude Design

Anthropic's conversational design tool. Not a plugin — it lives on claude.ai, separate from Claude Code. Describe what you want in chat, get working mockups on a canvas, refine with comments.

Inherits your org's design system (colors, typography, components) automatically — so output is already on-brand. Hands off cleanly to Claude Code for development.

HOW TO TRY IT

Open claude.ai/design with a Pro / Max / Team / Enterprise account.

Currently in research preview — Enterprise default-off, may need admin to enable.

WHAT YOU CAN BUILD
UI mockups Interactive prototypes Presentations Landing pages Dashboards
EXPORT FORMATS
.zip .pdf .pptx standalone HTML → Claude Code handoff
WHEN TO REACH FOR IT

Before writing a single line — sketch the UI conversationally, get stakeholder sign-off on the look, then hand the design to Claude Code as a spec.
